# ABSTRACT

The **Library Management System** is a web application developed to computerize the day-to-day operations of a library. It replaces the manual register-based system with an automated solution that manages books, categories, members and book-issue transactions. The application allows a librarian to add, edit and delete books, categories and members, issue books to members with a due date, record returns, calculate overdue fines automatically, and view complete issue history. A dashboard presents summary statistics and charts so the library status can be understood at a glance.

The system is built with the **CodeIgniter 3** PHP framework, uses **BladeOne** for clean template-based views, and a modern user interface styled with **Tailwind CSS v4** following the **TailAdmin** design system. It uses **Alpine.js** for interactive behaviour, **ApexCharts** for dashboard charts, and **SQLite** as the default database (a MySQL schema is also provided). The application supports light and dark themes and is fully responsive.
