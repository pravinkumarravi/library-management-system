# 8. SCREENS AND USER INTERFACE WALKTHROUGH

The interface is built with the **TailAdmin** design system: the Outfit font, a brand (indigo) colour palette, soft shadows, rounded cards and full light/dark theme support. Below is a description of every screen.

## 8.1 Login Screen (`/auth/login`)

- **Left panel:** "Back to dashboard" link, a large **Sign In** heading, "Enter your username and password to sign in!", Google/X style sign-in buttons (decorative), an "Or" divider, **Username** and **Password** fields (with a show/hide password eye toggle), a "Keep me logged in" checkbox, "Forgot password?" link and a full-width **Sign In** button. An inline error alert appears for invalid credentials.
- **Right panel:** a dark `brand-950` panel decorated with grid patterns, the application logo and a tagline.
- **Floating button:** bottom-right circular button toggles dark/light mode.

## 8.2 Admin Layout (shared by all pages after login)

- **Sidebar:** collapsible 290px ⇄ 90px. Logo (full/collapsed variants). Groups:
  - **Menu** — Dashboard, Books, Categories, Members.
  - **Issues** — Issued Books, Overdue, History.
  The active item is highlighted in brand colour; on mobile it becomes a slide-in drawer with a dark overlay.
- **Header:** sidebar toggle, mobile menu button, logo (mobile), search box that searches books, theme toggle, notification bell with dropdown, and a user menu with the logged-in user's name and **Sign Out**.
- **Content area:** page breadcrumb (Home / page title), flash alert area, then the page content.
- **Preloader:** brand spinner shown briefly on page load.

## 8.3 Dashboard (`/dashboard`)

- Four metric cards: **Books** (available copies pill), **Members** (categories pill), **Issued** (returned pill) and **Overdue** (active-issues pill).
- **Issues by Month** — vertical bar chart (ApexCharts) of the last 12 months.
- **Collection Status** — radial gauge showing the percentage of copies available, with Total Copies / Available / Issued statistics and a "this month" pill.
- **Top Categories** — progress bars showing books per category with percentages.
- **Recent Issues** — table of the latest transactions with book (icon + title + author), member, issue/due dates and status badges (Issued / Overdue / Returned), plus a **See all** link.

## 8.4 Books (`/books`)

Search box (title/author/ISBN), **+ Add Book** button and a table with Title, Author, ISBN, Category, Copies (available/total pill) and **Edit / Delete** actions.

**Add/Edit Book form:** Title, Author, ISBN, Publisher, Year, Category (dropdown) and Total Copies.

## 8.5 Categories (`/categories`)

**+ Add Category** button and a table with Name, Description, Books (count pill) and **Edit / Delete** actions. The form has Name and Description fields.

## 8.6 Members (`/members`)

Search box (name/email/phone), **+ Add Member** button and a table with Name, Email, Phone, Membership date, Active (issued-count pill) and **Edit / Delete** actions.

**Add/Edit Member form:** Name, Email, Phone, Membership Date, Address and Status (active/inactive).

## 8.7 Issued Books (`/issues`)

**+ Issue Book** button and a table of currently issued books: Book (title + author), Member, Issue Date, Due Date and a **Return** action.

**Issue a Book form:** Member dropdown, Book dropdown (only books with available copies, showing how many are available) and Due Date (defaults to 14 days ahead).

## 8.8 Overdue Books (`/issues/overdue`)

A **View Issued** button and a table listing overdue books with Book, Member, Due Date, **Days Late** (red pill) and **Est. Fine** (₹, red) plus a **Return** action.

## 8.9 Issue History (`/issues/history`)

All transactions with Book, Member, Issue Date, Due Date, Return Date, **Status** pill (Issued/Returned) and **Fine**, plus a **+ Issue Book** button.

## 8.10 Dark Mode

Every screen switches to a dark theme via the theme toggle (stored in `localStorage` and applied immediately to prevent flash). Cards, tables, forms, the sidebar and the header all have matching `dark:` styles.
