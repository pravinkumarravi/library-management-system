# 9. CONCLUSION, LIMITATIONS, FUTURE ENHANCEMENTS AND BIBLIOGRAPHY

## 9.1 Conclusion

The **Library Management System** was successfully designed, implemented and tested as a B.C.A. mini project. It demonstrates a complete web application built with the CodeIgniter 3 MVC framework, the BladeOne templating engine, a modern Tailwind CSS v4 / TailAdmin interface and a versioned database schema managed through CLI migrations.

The application meets all the stated objectives:

- Secure login for the librarian.
- Complete management of books, categories and members.
- Issue/return workflow with automatic copy-count updates.
- Automatic overdue detection and fine calculation.
- An informative dashboard with cards, charts and recent transactions.
- A responsive, modern interface with light and dark themes.

The system is easy to deploy (SQLite needs no separate database server), easy to operate, and its modular MVC structure makes it easy to extend. The project also gave practical experience of the software development life cycle — requirements analysis, system design, database design, implementation, testing and documentation.

## 9.2 Limitations

1. **Single-user:** only one librarian account is supported; there are no role-based permissions.
2. **No member self-service:** members cannot log in to view their own borrowings.
3. **No notifications:** overdue reminders via e-mail/SMS are not implemented.
4. **No barcode/RFID:** books are selected from dropdowns rather than scanned.
5. **Basic reporting:** reporting is limited to the dashboard summary; no printable reports are generated.
6. **Data entry validation** is primarily server-side via CodeIgniter's form validation, but advanced validations (e.g., ISBN format) are not included.

## 9.3 Future Enhancements

- Multi-user authentication with roles (admin, librarian, member).
- Member portal for viewing dues and history online.
- E-mail/SMS reminders for overdue books.
- Barcode and QR-code support for faster issue/return.
- Fine payment tracking and printable receipts.
- Advanced reports and export to PDF/Excel.
- Backup and restore for the database.
- Deploy to a production web server with HTTPS.
