# 7. TESTING

Testing verifies that every module behaves as expected. Both **functional testing** (through the browser) and **structural validation** (no PHP errors, correct HTTP responses) were performed.

## 7.1 Test Environment

- OS: Windows
- Server: PHP built-in development server (`php -S localhost:8000`)
- Browser: Chrome/Edge
- Database: SQLite
