# 3. INTRODUCTION

## 3.1 Overview

A library is the heart of an educational institution. Managing a library manually involves recording every book, every member and every issue/return transaction in registers. This becomes slow, error-prone and difficult to track. The **Library Management System (LMS)** is a web-based application that automates these operations. It is a B.C.A. mini project developed to demonstrate the complete software development life cycle — analysis, design, implementation, testing and documentation.

The application is a single-user (librarian) system protected by a login. Once logged in, the librarian can:

- View a dashboard with statistics and charts about the library.
- Manage the catalogue of **books** and **categories**.
- Manage registered **members**.
- **Issue** a book to a member with an automatic due date.
- **Return** a book and record the return.
- View **currently issued** books, **overdue** books and full **issue history**.
- Automatically calculate overdue **fines**.

## 3.2 Purpose

The purpose of the project is to:

1. Provide a fast and reliable way to record library transactions.
2. Reduce manual effort and human errors in book-keeping.
3. Give instant visibility into which books are issued, available or overdue.
4. Automate fine calculation for late returns.
5. Provide a clean, modern, easy-to-use interface.

## 3.3 Objectives

- To design a database that stores books, categories, members and issues.
- To implement secure login authentication for the librarian.
- To implement full CRUD (Create, Read, Update, Delete) operations for books, categories and members.
- To implement the issue and return workflow with due-date tracking.
- To highlight overdue books and compute fines automatically.
- To present summary information on a dashboard using charts and widgets.
- To build the interface with a modern, responsive, themeable design.

## 3.4 Scope

The scope of the current version is limited to a single librarian user managing a small-to-medium library. It covers catalogue management, member management, circulation (issue/return) and reporting through a dashboard. Online public access, member self-service portals, SMS/e-mail notifications and advanced reporting are out of scope for this version and are listed as future enhancements.

## 3.5 Key Features

| Feature | Description |
| --- | --- |
| Login / Logout | Secure authentication for the librarian (default: `admin` / `admin123`). |
| Dashboard | Summary cards (Books, Members, Issued, Overdue), a monthly issues bar chart, a collection-status radial gauge, top categories and recent issues table. |
| Books | Add, edit, delete and search books with title, author, ISBN, publisher, year, category and copy counts. |
| Categories | Add, edit and delete book categories; category-wise book count. |
| Members | Add, edit, delete and search members with contact and membership details. |
| Issue Book | Select member, select an available book, choose a due date (default +14 days). |
| Return Book | One-click return; the book's available copies are updated and fine is recorded. |
| Overdue | Lists issued books whose due date has passed, with days late and estimated fine (₹5/day). |
| History | Complete record of every transaction with status (Issued / Returned) and fine. |
| Dark Mode | The entire interface switches between light and dark themes. |
| Migrations | Database schema is managed through CLI migrations. |

## 3.6 Technology Overview

- **PHP 8** — server-side scripting language.
- **CodeIgniter 3** — lightweight PHP MVC framework.
- **BladeOne** — Blade-style templating engine for views.
- **Tailwind CSS v4** — utility-first CSS framework for the UI.
- **TailAdmin** — open-source admin dashboard design system used for layout and components.
- **Alpine.js** — lightweight JavaScript framework for interactive behaviour (menus, toggles, dropdowns).
- **ApexCharts** — charting library used for dashboard charts.
- **esbuild** — JavaScript bundler that packages Alpine.js and ApexCharts locally.
- **SQLite** — default zero-configuration database; MySQL schema also provided.
